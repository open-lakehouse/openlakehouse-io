The **Open Data Engineering Reference** is a free, open wiki on [open source data engineering](/open-source-data-engineering): open table formats, catalogs, query engines, pipelines, and the AI agents that work on them. Its center of gravity is the [open lakehouse](/wiki/Open_lakehouse). It is part of [openlakehouse.io](https://openlakehouse.io), and until November 2026 it was called the Open Lakehouse Wiki.

## Aims

- Neutral, vendor-neutral articles that explain how open data engineering technology works and how the pieces fit together.
- Every checkable fact linked to a primary source, with the date it was last verified.
- Pages that work well for people, search engines and AI assistants alike: a clear definition first, one idea per paragraph.

## Contributing

Every page is a Markdown file in [the site's repository](https://github.com/open-lakehouse/openlakehouse-io/tree/main/src/content/wiki). Anyone with a GitHub account can suggest a change: use the "Edit on GitHub" link on any page and open a pull request, which a maintainer reviews before it goes live. Read the [style guide](/wiki/Project:Style_guide) first.
