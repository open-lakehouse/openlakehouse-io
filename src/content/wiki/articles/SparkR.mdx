**SparkR** is the R package that ships with [Apache Spark](/wiki/Apache_Spark) and lets R programs use Spark: it provides a distributed data frame, the `SparkDataFrame`, with selection, filtering and aggregation, and access to Spark's machine learning library.[^guide] SparkR is deprecated as of Spark 4.0.0 and will be removed in a future version, but it is still part of every release up to Spark 4.3.0.[^guide][^jira49347] The Spark project points R users to sparklyr, a separate R package for Spark.[^zzz]

## Status

SparkR was deprecated in Spark 4.0.0 under SPARK-49347, after a vote on the Spark dev mailing list.[^jira49347][^r400] The deprecation shows up in three places in Spark 4.x:

- **Programming guide.** The SparkR guide opens with the sentence that SparkR is deprecated from Spark 4.0.0 and will be removed in a future version.[^guide]
- **Migration guide.** The SparkR migration guide says, under "Upgrading from SparkR 3.5 to 4.0", that SparkR is deprecated and will be removed in a future version.[^n1]
- **Startup message.** When the package is attached, SparkR prints a warning that it is deprecated and recommends sparklyr. Setting the environment variable `SPARKR_SUPPRESS_DEPRECATION_WARNING` to any non-empty value hides the message.[^zzz]

SparkR has not been removed. The `R/pkg` directory is present at the v4.1.0, v4.2.0 and v4.3.0 tags, with the package version matching each Spark release.[^desc] The Spark 4.1.0 release notes do not mention SparkR. The 4.2.0 release notes list maintenance work on it, such as Java 25 support and dropping support for R 3.x, and none of the 4.x release notes announce a removal.[^n2][^r420][^n3]

## Why it was deprecated

The proposal came from Shivaram Venkataraman, who created the original SparkR package as research at UC Berkeley. In an August 2024 thread on the Spark dev mailing list he argued that sparklyr is more idiomatic R than SparkR's Scala-like API, that contributions to SparkR had slowed, that sparklyr's newer Spark Connect based architecture removed the need to align its version with Spark's, and that sparklyr is maintained on CRAN while SparkR could not stay there under Spark's release process.[^discuss] The vote to deprecate SparkR followed on 21 August 2024, and the deprecation was merged for Spark 4.0.0.[^n4][^jira49347]

## History

Spark 1.4.0 was the first release to package SparkR, described in the release notes as an R binding built on Spark's then-new DataFrame API.[^n5] The SparkR package in Spark 4.3.0 requires R 4.0 or later and Java 17 or later.[^desc]

## How it works

SparkR starts or connects to a Spark application through `sparkR.session()`, which creates a `SparkSession`. From RStudio or another R environment, SparkR uses `SPARK_HOME` to find a Spark installation and can download one if none is found.[^guide] R code talks to the Spark driver JVM through a backend in Spark core (`org.apache.spark.api.r.RBackend`).[^n6] The guide also documents running R functions on the data with `dapply` and `gapply`, Apache Arrow for faster transfer between the JVM and R, and MLlib model training.[^guide]

The following R example runs with the Spark 4.3 distribution. It starts a session, converts the built-in `faithful` data frame to a `SparkDataFrame` and filters it.

```r
library(SparkR)
sparkR.session(appName = "faithful-example")

df <- createDataFrame(faithful)
head(filter(df, df$waiting < 50))

sparkR.session.stop()
```

## Comparison with sparklyr

|  | SparkR | sparklyr |
| --- | --- | --- |
| Maintained by | The Apache Spark project, inside the Spark repository[^desc] | A separate open source project (github.com/sparklyr/sparklyr)[^sparklyr] |
| Status | Deprecated since Spark 4.0.0[^jira49347] | Recommended by the SparkR startup message[^zzz] |
| Installation | Ships with the Spark distribution; not maintained on CRAN[^discuss] | `install.packages("sparklyr")` from CRAN[^sparklyr] |
| API style | Its own functions over `SparkDataFrame` (`filter`, `select`, `agg`)[^guide] | Described in the deprecation proposal as more idiomatic R[^discuss] |
| Spark Connect | Not a Spark Connect client; connects through the R backend in the driver | `spark_connect(method = "spark_connect")`[^sparklyr] |
